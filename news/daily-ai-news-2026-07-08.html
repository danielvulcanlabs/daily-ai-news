Fable 5 Cybersecurity Safeguards — Defense-in-Depth Architecture
  • Dùng safety classifiers phân loại requests theo spectrum: benign → ambiguous → harmful. Safety margin cố tình rộng hơn normal để catch jailbreaks.
  • Jailbreak taxonomy: Minor (trong safety margin) → Narrow harmful (unlock specific behavior) → Universal (unblock toàn bộ class). Fable 5 chưa có universal jailbreak được confirm.
  • 4 severity dimensions mới: capability gain, breadth of gain, ease of weaponization, discoverability — tương tự CVSS cho software vulnerabilities.
  • New classifier block Amazon-reported technique trong >99% cases — false positive tăng nhẹ trên routine coding/debugging tasks.
  • Pre-release gov access & 24/7 jailbreak monitoring team cho mọi frontier model từ nay về sau.

Open Weight MoE
marktechpost.com
Hy3 Architecture: 295B MoE với Multi-Token Prediction
  • 192 experts, top-8 routing — chỉ 21B active parameters/token. Sparse MoE giảm serving cost đáng kể so với dense model cùng capability level.
  • Multi-Token Prediction (MTP) layer 3.8B params — predict nhiều tokens đồng thời, tích hợp speculative decoding qua vLLM & SGLang để tăng throughput.
  • Hy3-FP8 checkpoint giảm VRAM footprint — recommend 8x H20-3e GPUs. reasoning_effort flag: no_think / low / high cho dynamic compute allocation.
  • Coreference tracking cải thiện: internal multi-turn issue rate từ 17.4% → 7.9%; MRCR long-dialogue benchmark từ 42.9% → 75.1%.
  • AngelSlim toolkit hỗ trợ quantization, low-bit methods & speculative sampling cho production deployment.

Memory Systems
arxiv.org
MemPro: Memory Systems as Evolvable Programs
  • Maintain version tree của runnable memory implementations — Evolving Agent chọn version promising, diagnose failures, tạo child versions qua edit-debug refinement.
  • Outperform strong static & prompt-level evolving baselines trên LongMemEval, LoCoMo, HotpotQA, NarrativeQA trong vài iterations.
  • Approach mới: thay vì cố định memory architecture, để system tự evolve memory logic dựa trên failure patterns — favorable performance-cost tradeoff.

arxiv.org
MemForest: Hierarchical Temporal Indexing cho Agent Memory
  • Break sequential bottleneck qua parallel chunk extraction — memory construction decoupled thành concurrent, independent operations.
  • MemTree: organize memory theo time-ordered trees thay vì flat global summaries — loại bỏ coarse-grained maintenance bottleneck.
  • LongMemEval-S: 79.8% pass@1 (best stateful baseline), construction throughput ~6x EverMemOS — critical cho production long-horizon agent systems.

Inference Optimization
epoch.ai / gartner.com
LLM Inference Economics 2026 — Cost Collapse Playbook
  • FP8 quantization trên H100: 1.3–2x throughput vs FP16, <2% quality loss trên instruction-tuned models — first optimization để apply.
  • KV cache quantization INT8/FP8 giảm VRAM 30–50%, free capacity cho concurrent requests. AWS Bedrock + Cerebras CS-3: ~5x token throughput, giảm cost 80%.
  • GPT-4 level performance: $30/M tokens (2023) → <$1/M (2026). Gartner dự báo cost 1T-param inference giảm 90%+ vào 2030. Tốc độ giảm dần: từ 10x/năm xuống 3–5x/năm sau 2027.

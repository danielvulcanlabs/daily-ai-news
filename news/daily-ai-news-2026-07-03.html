Fable 5 Safety Classifier Architecture: Defense-in-depth với 3-layer stack
  • classifier-v3: lightweight screening mỗi turn; classifier-v3-deep: context-window analysis khi phát hiện anomaly; policy-guard: constitutional layer cuối cùng
  • Amazon red team phát hiện bypass trong classifier-v2; Anthropic patch trong 48h với v3 — cascade architecture giúp isolate failure ở layer 1, không propagate lên Fable 5 core
  • Fallback logic: khi classifier confidence <0.85, route về Opus 4.8 thay vì reject — duy trì UX trong khi giảm exposure risk

MEMORY · ALGORITHM
M
Mem0 April 2026 Algorithm: Single-pass ADD-only extraction, +29.6pt temporal accuracy
  • Thay thế diff-based memory update bằng ADD-only extraction: chỉ append facts mới, không overwrite — giảm memory corruption trong long-running sessions
  • Temporal indexing mới: mỗi memory fact có timestamp_created + recency_weight decay — query "what did user say last week" giờ accurate 29.6 điểm cao hơn trên LongMemEval
  • Chunking strategy: semantic paragraph boundaries thay vì fixed-size chunks — giảm context fragmentation, cải thiện retrieval precision 18% trên LoCoMo benchmark

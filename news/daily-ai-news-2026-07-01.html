Token billing amplification trong agentic workflows — tại sao 1,000x không phải typo
  • Transformer architecture re-processes full conversation history mỗi turn — 20-turn session với 10K tokens/turn = ~200K input tokens ở turn 20 dù total input chỉ là 200K
  • MCP tool schemas: 30 registered tools → mỗi request đều include schema defs của tất cả 30 tools dù agent chỉ dùng 2 — potential waste hàng nghìn tokens/request
  • Copilot billing: không có fallback model sau June 1 — khi credits hết, request bị reject hoàn toàn. Default không có spending cap → billed không giới hạn

Protocol Design scworld.com
MCP stateless migration: production deployment implications
  • Previous: client phải gửi Mcp-Session-Id trong mỗi request → server cần sticky sessions + shared session stores + DPI-aware gateways
  • New stateless core: route trên Mcp-Method header thay vì session ID → plain round-robin load balancer là đủ; tools/list responses có thể được cached theo ttlMs
  • Đi kèm MCP Apps extension (server-rendered UIs) và Tasks extension (long-running work) — nhưng loại bỏ server-initiated prompts, source của nhiều security issues trước đây
